# Nguyễn Huy Thịnh (Ben) - Portfolio Website

> Modern Luxury Executive Portfolio & Resume for Nguyễn Huy Thịnh (Ben) - Senior Sales Manager | Hospitality Sales Leader.

## 🌟 Features
- **Modern Luxury Hospitality UI**: Tailored for luxury beachfront resorts and executive hospitality sales.
- **Trilingual Support**: English (EN), Traditional Chinese (ZH 繁體中文), and Vietnamese (VI).
- **Dual-Storage Contact System**:
  - Direct email delivery to `bennguyenht54@gmail.com`.
  - Automatic cloud backup to **Google Firebase Firestore** (`contact_messages` collection).
- **Dark/Light Mode**: Smooth theme toggling with local storage memory.
- **Responsive Design**: Flawless experience across mobile, tablet, and desktop.

## 🚀 Live Deployment
- **Hosting Platform**: Vercel
- **Database & Cloud Backup**: Google Firebase Firestore
- **Version Control**: GitHub
